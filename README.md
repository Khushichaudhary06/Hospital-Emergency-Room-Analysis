# 🏥 Hospital Emergency Room Analysis Dashboard


## Project Overview

The **Hospital Emergency Room Analysis Dashboard** is an interactive data analysis project developed using **Microsoft Excel**.
The dashboard provides a comprehensive view of emergency room performance by analyzing **no of patient, waiting time, satisfaction scores, admissions, demographics, and department referrals**.
This project demonstrates practical skills in **data cleaning, data analysis, Pivot Tables, Pivot Charts, Slicers, and interactive dashboard development**.


## Project Objectives

The main objectives of this project are to:

- Analyze the total number of emergency room patients
- Monitor average patient waiting time
- Evaluate patient satisfaction
- Compare admitted and non-admitted patients
- Analyze patient distribution by age group
- Analyze gender distribution
- Identify department referral patterns
- Track monthly and yearly emergency room activity
- Create an interactive and user-friendly dashboard



## Key Performance Indicators

| KPI | Description |
